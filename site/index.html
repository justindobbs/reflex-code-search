The search loop

From a question to a short list you can trust.

REFLEX keeps each step clear, so you can see how a natural-language query turns into useful source files.

01 / DISCOVER→

Collect the code

Walk the repository, respect nested .gitignore rules, and skip generated and binary files.

02 / SCORE→

Rank likely matches

Combine term, phrase, AST-extracted definitions, and docstring signals to find files related to your question.

03 / GATE→

Make decisions visible

Accept, reject, or flag uncertain results with a configurable confidence gate.

04 / INSPECT✓

Follow the evidence

Review candidate scores and session telemetry. Add optional Jev scoring when useful.

Small by design

A useful primitive for people and tools.

Start at the command line. Bring the same search loop into your own Python workflow when you need it.

Local / 01

AST-aware Python understanding

Extracts class names, function signatures, docstrings, and imports using the stdlib ast module. Non-Python files fall back to regex heuristics.

ZERO DEPS
Control / 02

Sync or async, your choice

Run locally in milliseconds, or score in parallel with AsyncJevScorer and configurable concurrency. The --async flag enables parallel Jev calls for live and smart-fallback modes.

ASYNCIO
Integrate / 03

Built for agents

Expose search as an MCP tool for AI agents, or use the zero-dependency Agent Skills file. Compatible with Windsurf, Claude Code, and any MCP host.

MCP + SKILLS
Extend / 04

Keep the results in your workflow

Use the CLI, consume structured JSON, call the Python API, or provide a custom scorer through a small protocol.

QUICKSTART / LOCALPYTHON 3.11+
# Install from the repository
python -m pip install -e .

# Search this codebase
reflex-search "Where are API errors handled?" .

# Async two-pass with Jev API
reflex-search "How does scoring work?" . --live --async

# Run as an MCP server for agents
pip install -e ".[mcp]" && reflex-search-mcp
