The search loop

Simple steps. Visible decisions.

REFLEX turns a natural-language question into candidate files, then shows the path each candidate took through the search loop.

01 / DISCOVER

Collect repository files

Walk the codebase, respect nested `.gitignore` rules, and skip common generated or binary files.

02 / SCORE

Rank likely matches

Use local term, phrase, definition, and docstring signals to estimate which files answer the question.

03 / GATE

Make the call explicit

Accept, reject, or mark a result uncertain using a configurable confidence gate.

04 / INSPECT

Follow the audit trail

See candidate decisions and session telemetry. Optionally escalate uncertain results to Jev.

Made to stay understandable

A focused building block, not a giant platform.

Use it from the terminal or plug the search loop into a Python workflow.

LOCAL / 01

Works without a service

Local scoring is the default, so searches work without network access, account setup, or an API key.

CONTROL / 02

Optional live scoring

Use Jev for live scoring or as a fallback for uncertain candidates when you choose to configure it.

INTEGRATE / 03

CLI and library API

Search from the command line, consume JSON output, or provide a custom scorer through a small protocol.
